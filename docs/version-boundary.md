# Earlier implementation and this build

The supplied local workspace was an empty Git repository. The complete build was implemented and evaluated there. When GitHub publication was explicitly requested, authenticated access revealed an existing public `cyash24f3/doculens` repository, with default-branch commit `d0a0731` and an existing Render demonstration. Its README, source inventory, history and deployment entry points were inspected at that point; the initial local-baseline claim refers to the supplied workspace, not the account's earlier repository.

The earlier project uses a root `doculens/` package, a different SQLite schema/CLI, local extractive answers, a 66-question benchmark, optional Bedrock, and a separate `public_demo.py` hosting entry point. This build uses `src/doculens/`, SQLAlchemy/Alembic, fenced database jobs, PostgreSQL/pgvector deployment, explicit fixture/disabled/provider contracts, a 200-intent benchmark and one compatible local-generation adapter. Copying it over the earlier default branch would change storage/API/hosting contracts without a tested upgrade path.

The publication choice is therefore a separate public **`cyash24f3/doculens-v2`** repository. No prior code/history, public deployment, private database or unrelated project is rewritten. The earlier repository remains independently runnable according to its own instructions; its historical verification claims have not been re-executed by this build. This separation is a version boundary, not a claim that the new code imported the old database.

To bring earlier content into this build, keep the old application/data intact, export the original source files through its existing source controls, and upload them here as new logical documents. That preserves source bytes but produces new document/version/chunk IDs; old traces and IDs are not interchangeable. A supported identity-preserving migration would need a dedicated export/import format and cross-version tests before combining the deployments. Do not point this build at an earlier SQLite file or replace a deployed `public_demo.py` command with this repository without changing and validating deployment settings.

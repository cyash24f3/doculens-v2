# Experiment decisions before the final test run

2026-09-30. No paid API was called.

- Initial development run `72dc777f-73c3-4a96-996b-b4cdfd022081` used the first dataset before the PDF track was added. It is exploratory and is not the final comparison.
- Three product demo questions were exercised with the local Qwen 3B model during integration. Returns and shipping were in the original test partition, so those entire source/theme groups were moved to development **before final evaluation**. The final split is manifest version 2, with 60 development and 140 test questions. Its SHA-256 is recorded in each final run. No final test result has influenced a retrieval parameter or prompt choice. Some themes from the first exploratory development run moved to the final comparison partition, so version 2 is a frozen comparison set rather than a pristine unseen held-out dataset. A fresh independently human-authored holdout is still needed.
- Final development retrieval run `aefde748-60b8-4c6b-b139-dcce38cafab3`: 42 answerable, 18 missing. Full-evidence@5: BM25 0.9524; dense 0.9524; hybrid 0.9286; reranked 1.0000. Reranked warm p95 139.1 ms, compared with hybrid 5.3 ms. These are AI-authored labels, not human accuracy measurements.
- Freeze retrieval settings: BM25 k1=1.5/b=0.75, exact normalized MiniLM, candidate limit=20, RRF constant=60/equal weights, cross-encoder MiniLM reranking. Default interactive method stays hybrid for latency; reranking is an explicit experiment. No benchmark-specific retrieval rule exists.
- Development-derived exploratory targets for final retrieval: each method full-evidence@5 >=0.85; warm sequential retrieval p95 <=250 ms. These describe this small benchmark and machine, not a production service level. Report unmet targets rather than changing the test set.
- Integration found that forcing one context passage per document could drop the second-ranked, required passage. Context now preserves ranking, removes strong overlap, and limits a document to two passages. This tradeoff can still lose questions needing more than two passages from one document.
- Qwen 3B failed supported-answer and conflict demo scenarios despite structurally valid output. Preserve `local-provider-smoke.json` and `local-provider-smoke-v2.json`. Field definitions were added to the prompt, version `grounded-claims-v2`; a larger free local model will be checked on development examples. Do not interpret valid citation IDs as answer quality.
- Human semantic review is pending. Automated judgment, if run, must identify the model, rubric, prompt, and lack of human calibration.

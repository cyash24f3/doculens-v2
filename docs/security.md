# Access, deletion and untrusted inputs

This is a single-administrator application with two fixed server-authorized corpora. Anonymous callers can read only `sample`. A bearer token of at least 24 characters grants administrator access to `sample` and `private`. Arbitrary workspace names are rejected, and document IDs cannot expand permission scope. Upload, removal, job inspection/retry, comparisons, traces, metrics and experiments require admin access. Provider generation requires admin access by default. The hosted service explicitly enables anonymous answers only for the controlled sample, with an atomic shared free request budget and no admin credential. Private corpora still require authorization before any quota reservation or provider request. Public quota state is disposable with Render disk replacement; provider account limits apply independently. Local scripted mode stays explicitly labeled.

Generate a token with `uv run python -c 'import secrets; print(secrets.token_urlsafe(32))'`, save it only in ignored `.env`, and paste it into Administrator access. The UI stores it in tab memory, not browser storage. This is a portfolio access model, not enterprise identity or tenancy. HTTP must stay loopback locally; use TLS if exposing a deployment.

Uploads accept bounded PDF/Markdown/UTF-8 text with validated extension, MIME, byte count and basic integrity. Original filenames are never paths or storage identifiers. Generated keys are UUIDs; file permissions are restricted. PDF extraction rejects encryption, corruption and empty/image-only content. OCR is not silently simulated. Bounds include 500 pages, 2 million extracted characters and 2000 chunks. Complex PDFs can still consume substantial parser resources; administration remains protected.

The browser uses `textContent` for every source, answer and error. It does not render arbitrary Markdown/HTML. Original source links accept only HTTP/HTTPS. A same-origin content-security policy rejects inline scripts and framing. The API bounds body sizes, text lengths, result counts and ID lists. SQLAlchemy parameterizes values. No source text or token is placed in default logs, and no model can execute shell commands or business actions.

`data/sample/prompt-injection.txt` is a deliberately malicious fixture excluded from normal sample search. The dedicated test/evidence script can ingest it in a temporary isolated corpus and record whether the real local model follows its instructions. A successful structural check is not prompt-injection immunity. The context clearly separates source data from instructions, but model behavior still requires observation.

Deletion tombstones all versions, removes all chunks and extracted text, fences jobs, unlinks raw files, increments corpus revision and purges associated traces. Default caches are invalidated immediately in the deleting process and cannot match the changed manifest in another. Historical evidence also becomes inaccessible. The final eligibility check protects requests whose source was removed/replaced before publication; requests completing after that check follow the bounded policy described in `architecture.md`. Copies already downloaded by clients and repository-provided public sample fixtures cannot be revoked.

Trace retention is seven days, with expiration checked at access time and old rows pruned on new query writes. Only administrators can inspect excerpts. Experiment endpoints contain summaries of fixed sample evaluation; they never index private uploads. Local benchmark files include sample passages and are ignored unless intentionally published. Database/file volumes need normal machine access protection and backups; this project does not encrypt the local database at rest or provide SSO.
